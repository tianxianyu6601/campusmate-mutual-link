# CampusMate 阶段 1 页面地图与权限表

## 登录前

未登录用户只能进入登录页面，并在同一页面完成：

- 登录
- 注册
- 重置密码

所有登录后页面都在页面函数入口调用 `require_login()`；直接输入页面 URL 时仍会被送回登录页。

## 统一页面状态

- 正常页：标题、简短说明、核心操作。
- 空状态：图标、状态标题、原因、下一步；不伪造业务数据。
- 加载状态：耗时算法继续使用 `st.spinner`，后续异步任务统一显示明确进度。
- 错误状态：可预期业务错误使用 `st.error`，不直接向用户暴露异常栈和密钥。
- 成功状态：表单提交使用 `st.success`，跳转前先提交服务端状态。

## 会话行为

- 登录成功：一次提交完成密码验证、服务端会话创建、Cookie 写入和首页跳转。
- 页面刷新：新 WebSocket 会话从 Cookie 恢复账号及允许持久化的匹配状态，URL 路由保持当前页面。
- 退出登录：先删除数据库中的会话令牌，再删除浏览器 Cookie，最后硬跳转到干净的登录会话。
- 会话令牌：浏览器保存随机原始令牌，数据库只保存 SHA-256 哈希，有效期为 7 天并随使用续期。
